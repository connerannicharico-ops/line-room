Building projections…

How it works. Game spreads and totals set each team's implied points, which move its pass attempts, carries, yards, and touchdowns using relationships fit on 2025 games. Each player gets a share of that volume from 2026 and 2025 usage, regressed toward snap-based priors, then efficiency and matchup adjustments. Weeks without a posted line use team ratings built from the lines that are posted (marked "est"). Step-scoring rules like yardage tiers and the completion % bonus are scored as expected values over a realistic range of outcomes, not just the average stat line.
